# Jesse Lesperance AI Agent Alerts (SMS)

- **Brand:** Jesse Lesperance
- **Program name:** Jesse Lesperance AI Agent Alerts
- **Sending number:** {{ site.sms_number }}

## What this program is

Jesse Lesperance runs automated AI agents that monitor systems, tasks, and workflows. This SMS program lets subscribers get text messages from those agents. There are two subscription types:

- **Event Alerts (`EVENT`):** a real-time text when an AI agent finishes a task, detects something that needs attention, hits an error, or needs a human to approve or review something. For example: *"Jesse Lesperance Alerts: Agent 'nightly-backup' completed successfully at 2:04 AM."*
- **Daily Digest (`DAILY`):** one summary text per day covering what the AI agents did in the previous 24 hours: tasks completed, open items, and anything that needs follow-up.

These are informational, non-marketing messages. No promotional or advertising content is sent through this program.

## How to opt in

**Text `EVENT` or `DAILY` to {{ site.sms_number }} to subscribe.**

1. Text the keyword **EVENT** (for real-time alerts) or **DAILY** (for the daily digest) to **{{ site.sms_number }}**.
2. You'll get a text asking you to confirm your subscription.
3. Reply **Y** to confirm. You're enrolled only after you reply Y.

You can subscribe to both by texting each keyword separately. Consent to receive these messages is not a condition of any purchase.

The **DAILY** flow is the same. The messages read:

- **Subscriber texts:** `DAILY`
- **Confirmation prompt:** "Jesse Lesperance AI Agent Alerts: Reply Y to confirm you want to receive a daily AI agent digest. 1 msg/day. Msg & data rates may apply. Reply HELP for help, STOP to opt out."
- **Subscriber replies:** `Y`
- **Enrollment confirmation:** "Jesse Lesperance AI Agent Alerts: You're subscribed to the daily AI agent digest. 1 msg/day. Msg & data rates may apply. Reply HELP for help, STOP to opt out."

## Message frequency

Message frequency varies based on agent activity. Event Alerts are sent when agent events happen. The Daily Digest is one message per day.

## Help and opting out

**Reply HELP for help, Reply STOP to opt out.**

- Reply **HELP** at any time to get help. You'll receive: *"Jesse Lesperance AI Agent Alerts: For help, email {{ site.sms_contact_email }} or visit lesperance.io/sms. Msg & data rates may apply. Reply STOP to opt out."*
- Reply **STOP** (or CANCEL, END, QUIT, UNSUBSCRIBE, STOPALL) at any time to opt out. You'll receive one final message confirming that you've been unsubscribed, and no more messages will be sent: *"Jesse Lesperance AI Agent Alerts: You have been unsubscribed and will receive no further messages. Reply START to resubscribe."*

Carriers are not liable for delayed or undelivered messages.
